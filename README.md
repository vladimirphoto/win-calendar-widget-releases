# Lumina Retouch

Настольное приложение для портретной ретуши фото (Windows / macOS / Linux). Python + PySide6 + OpenCV.

## Запуск

1. Установите Python 3.10–3.13 (на Windows отметьте «Add Python to PATH»).
2. Windows: двойной клик по `run.bat`. Остальные системы:
   ```
   pip install -r requirements.txt
   python app.py
   ```
3. Чтобы получить обычную программу `.exe`: запустите `build_exe.bat` → `dist\Lumina Retouch\`.

## Что умеет

- **Кожа**: сглаживание с сохранением текстуры (частотное разложение), удаление мелких дефектов,
  выравнивание тона/покраснений, автоопределение лиц и подстройка маски под тон кожи.
- **Свет и цвет**: экспозиция, контраст, света/тени, температура, оттенок, насыщенность, красочность.
- **Детали**: чёткость, резкость (кожу заостряет слабее), виньетка.
- **Работа сериями**: список фото, «Применить ко всем», режим «Синхронизировать со всеми»,
  копирование/вставка настроек, пресеты (встроенные и свои), пакетный экспорт.
- **До / После**: разделитель (Ctrl+B) и удержание Пробела для просмотра оригинала.
  Колесо мыши — зум, двойной щелчок — по размеру окна.
- **Экспорт**: JPEG / PNG / TIFF / WEBP, изменение размера, EXIF и ICC-профиль сохраняются.
- RAW: `pip install rawpy` — и форматы CR2/CR3/NEF/ARW/DNG откроются.

## Ограничения

- Конвейер 8-битный; превью строится по уменьшенной копии (до 2000 px), экспорт — по полному размеру.
- Лица ищутся каскадами Хаара (фронтальные лица). Если лицо не найдено, маска строится только по цвету кожи.
- Пока нет: ретушь формы лица/тела (пластика), отбеливание зубов, кисти и локальные маски.
